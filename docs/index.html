How it is made怎么做出来的

  • AScript in markdown. One file per episode: timeline, voice-over, on-screen text. Plain text, diff-able, correctable.
  • BRendered by one command. ./make.sh A-001 → voice, frames, subtitles, MP4.
  • CSources are checked. Etymology claims cite a dictionary or a paper; corrections get credited in the description.
