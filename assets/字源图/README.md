# 字源图（字形演变素材）

一集一个目录，命名 `<EP>-<汉字>`，例如 `A-001-火/`。

```
A-001-火/
├── 01-jiaguwen.png    甲骨文
├── 02-jinwen.png      金文
├── 03-zhuanshu.png    篆书（有则放）
└── 04-kaishu.png      楷书
```

规则：

- 背景透明 PNG，最短边 ≥ 1200px（1080×1920 竖屏留足放大余量）。
- 每张图必须有来源：优先使用公共领域拓本/摹本（《说文解字》刻本、甲骨文合集等），来源写进 `source.md`。
- **不接受**来源不明的扫描件、他人二创描摹、商用字库截图。
- 同一集内所有字图必须同一笔触风格，否则剪出来会跳。
