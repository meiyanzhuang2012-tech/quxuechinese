# 趣学汉语 · QuXue Chinese — production repo

> 中文版：[README.zh-CN.md](README.zh-CN.md)

**One character. One minute. One "oh, that's why."**

This is the working repo behind **趣学汉语 (QuXue Chinese)** — the short-video account where Chinese characters,
words, idioms and poetry explained in English, under 60 seconds, no talking head.
It is not a course and not a phrasebook. Every episode answers exactly one question:
*why does this look / mean the way it does?*

Everything that goes into an episode lives here as plain text and assets, so an episode can be
re-rendered, translated, corrected or re-cut a year later without asking anyone.

- 🎬 Watch: [YouTube @quxuechinese](https://www.youtube.com/@quxuechinese)
- 🗂 Landing page & free character-card pack: GitHub Pages from `main` / `/docs` (source in [`docs/`](docs/))
- 🐞 Corrections are welcome and treated as a priority: open an [issue](https://github.com/meiyanzhuang2012-tech/quxuechinese/issues)

## What is in here

| Path | What it holds |
|---|---|
| `scripts/episodes/` | **One markdown file per episode** — timeline, English voice-over line by line, on-screen text, shot notes. This is the source of truth. |
| `scripts/选题库/topics.json` | Topic backlog (30 seeded, extensible), each with `id`, Hanzi, angle, platform. Every episode's front matter carries its `topic_id`. |
| `scripts/render.py` | Renderer: markdown → TTS → slide frames → ffmpeg → MP4 + SRT. |
| `assets/字源图/` | Glyph-evolution images (oracle bone → bronze → seal → regular), one folder per episode. |
| `assets/fonts/`, `assets/audio/` | Licensed fonts and SFX actually used in the cuts. |
| `renders/成片/` | Rendered outputs (`EP-SLUG.mp4` + `.json` manifest). Not the archive — re-renderable from source. |
| `subtitles/` | `.srt` per episode, generated by the renderer. |
| `docs/` | GitHub Pages site: landing page, character-card pack download, script spec. |
| `make.sh` | One-command entry point. |

## Quick start

```bash
./make.sh --list                 # list episodes
./make.sh A-001 --none           # silent cut, ~30s — use this to check layout & hook
./make.sh A-001                  # full cut with local Qwen3-TTS English voice
./make.sh A-001 --edge           # fallback: edge-tts
./make.sh --all --none           # batch silent cuts
```

Output: `renders/成片/A-001-huo.mp4`, `subtitles/A-001-huo.srt`, and a JSON manifest next to the video.

Requirements: `ffmpeg` (libx264 + aac + libass), `python3` + `pillow`, and either a local
TTS service (`/tts` endpoint, see `scripts/render.py`) or `edge-tts`. Nothing else.

## Episode format

An episode is one markdown file with YAML front matter and a shot table. Adding a video means
adding a file — no code change, no CMS, no database:

```markdown
---
ep: A-001
line: A
slug: huo
title_en: Fire, drawn 3,000 years ago and never updated
hanzi: 火
topic_id: 1
platform: 双        # 双 = YouTube + TikTok, YT = YouTube first, TT = TikTok first
status: draft
---

| time | vo_en | onscreen_zh | visual |
|---|---|---|---|
| 0:00 | Three thousand years ago, someone scratched fire onto a bone. | 火 | paper texture, one big glyph |
```

Rules and edge cases: [`docs/脚本规范.md`](docs/脚本规范.md) (Chinese).

## Why a repo and not a folder of MP4s

A video is a **build artifact**. The text, the glyph sources and the timing are the asset.
Keeping them in git means: corrections are diff-able, a 40-second cut can be re-cut to 30 for
another platform without re-recording, translation is a fork away, and an editor who leaves
takes nothing with them.
